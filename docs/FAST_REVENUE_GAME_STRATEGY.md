## 🥈 گزینه دوم: Idle/Clicker Game با HTML5

اگر نمی‌خواهید کد آماده بخرید، سریع‌ترین راه ساخت:

### بازی پیشنهادی: "Empire Idle" — یک بازی Clicker استراتژیک

**مفهوم**: بازیکن از یک روستای کوچک شروع می‌کند، با کلیک کردن منابع جمع می‌کند، ارتش می‌سازد، و به تدریج idle می‌شود (اتوماتیک).

**نقشه راه ۸ هفته‌ای**:

| هفته | کار |
|------|-----|
| ۱-۲ | HTML/CSS/JS ساده — کلیک collecting resources + upgrade buttons |
| ۳-۴ | Auto-generation (idle mechanic) + Prestige system |
| ۵-۶ | Multiplayer leaderboard + simple PvP (send troops, get resources) |
| ۷-۸ | Monetization (watch ad for 2x boost, buy gold for speed-up) + launch |

**مزایا**:
- با HTML/JS خالص — هیچ بکندی لازم نیست در ابتدا
- Firebase Realtime Database برای leaderboard رایگان (تا ۱۰۰K کاربر)
- AdMob / Google Ads مستقیم در صفحه وب
- **درآمد از روز اول** با تبلیغات rewarded video

## 💰 مدل‌های درآمدزایی — به ترتیب سرعت

### ⚡ سریع‌ترین (روز اول)

**Rewarded Video Ads (AdMob / Unity Ads)**
- بلافاصله بعد از نصب کاربر
- هر ۱۰۰۰ نمایش = $2-15
- مناسب برای Idle/Hyper-Casual

### 🔥 متوسط (هفته اول-دوم)

**In-App Purchases (IAP) — Starter Pack**
- پک شروع $0.99-2.99
- ۳۰-۴۰٪ کاربران در روز اول پک شروع را می‌خرند
- مناسب برای MMO/Strategy

### 🐢 کند ولی پایدار

**Subscription / Battle Pass**
- $4.99-9.99 ماهانه
- درآمد پیش‌بینی‌پذیر
- نیاز به retention بالا (۳۰+ روز)
