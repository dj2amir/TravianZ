## نیازمندی‌های هاست

| نیازمندی | حداقل | بررسی در سی‌پنل |
|----------|:-----:|------------------|
| **PHP** | 8.0 یا بالاتر | `cPanel → Select PHP Version` |
| **MySQL / MariaDB** | 5.7+ | `cPanel → MySQL Databases` |
| **Cron Job** | حداقل هر ۵ دقیقه | `cPanel → Cron Jobs` |
| **فضای دیسک** | ۵۰۰ مگابایت | `cPanel → Disk Usage` |
| **حافظه PHP** | ۱۲۸ مگابایت | `cPanel → Select PHP Version → Options → memory_limit` |
| **mod_rewrite** | فعال (پیش‌فرض) | معمولاً روی همه هاست‌ها فعاله |

### افزونه‌های ضروری PHP

مطمئن شو این افزونه‌ها در `Select PHP Version → Extensions` تیک خورده باشن:

- ✅ `mysqli` یا `mysqlnd`
- ✅ `mbstring`
- ✅ `json`
- ✅ `fileinfo`
- ✅ `openssl`

> 💡 **هاست‌های پیشنهادی ایرانی**: لیمو هاست، ابر آروان، پارس پک، میزبان فا — همشون PHP 8.x و Cron Job دارن.

## گام ۱: آپلود فایل‌ها

### روش اول: File Manager (ساده‌تر)

1. وارد سی‌پنل شو → `File Manager`
2. برو تو پوشه `public_html` (ریشه سایت)
3. دکمه `Upload` رو بزن
4. فایل ZIP پروژه رو انتخاب کن و آپلود کن
5. بعد از آپلود، روی فایل ZIP کلیک راست → `Extract`
6. مطمئن شو فایل‌ها **مستقیم تو public_html** هستن (نه تو یه زیرپوشه)

```
public_html/
├── index.php          ✅ درسته
├── install/
├── GameEngine/
├── Templates/
├── gpack/
├── var/
├── cron.php
└── ...

public_html/TravianZ/  ❌ غلط — یه سطح اضافه
```

### روش دوم: FTP (برای فایل‌های حجیم)

با FileZilla یا هر کلاینت FTP دیگه وصل شو و کل پروژه رو به `public_html` آپلود کن.

## گام ۲: ساخت دیتابیس

1. تو سی‌پنل برو `MySQL Databases`
2. یه دیتابیس جدید بساز (مثلاً `travian_db`)
3. یه کاربر MySQL بساز (مثلاً `travian_user`)
4. یه رمز قوی برای کاربر بذار
5. کاربر رو به دیتابیس اضافه کن (`Add User to Database`)
6. **دسترسی `ALL PRIVILEGES`** رو به کاربر بده

### 📝 اطلاعاتی که باید یادداشت کنی

| مورد | مثال | یادداشت |
|------|------|---------|
| Database Name | `cpaneluser_travian_db` | ⚠️ کامل (با پیشوند) |
| Username | `cpaneluser_travian_user` | ⚠️ کامل (با پیشوند) |
| Password | `********` | رمزی که ساختی |
| Host | `localhost` | معمولاً همین |

## گام ۳: تنظیم Permissions

### از File Manager سی‌پنل:

۱. روی پوشه `var` کلیک راست → `Change Permissions` → `755` ✅  
۲. روی پوشه `var/log` کلیک راست → `Change Permissions` → `755`  
۳. روی پوشه `install` کلیک راست → `Change Permissions` → `755`

> ⚠️ **نکته مهم**: اگر هاست از **suPHP** استفاده می‌کنه (اکثر هاست‌های ایرانی)، نیازی به `777` نیست — `755` کافیه. suPHP فایل‌ها رو با یوزر خودت اجرا می‌کنه، پس همیشه دسترسی نوشتن داره.

## گام ۵: تنظیم Cron Job ⚠️ بحرانی!

**Cron Job قلب تپنده بازی شماست. بدون Cron، بازی کار نمی‌کنه!**

Cron Job مسئول پردازش این موارد در هر تیک ۶۰ ثانیه‌ای هست:

- 🏗️ تکمیل ساخت و سازها (صف ساختمان)
- ⚔️ انجام نبردها (حمله، دفاع، غارت)
- 🏃 حرکت نیروها (رسیدن به مقصد، برگشت)
- 🌾 تولید منابع (چوب، خشت، آهن، گندم)
- 🏅 مدال‌ها و آمار بازیکنان
- 🧹 پاکسازی گزارش‌های قدیمی

---

### روش اول: Cron Job با PHP CLI ✅ (توصیه شده)

1. تو سی‌پنل برو: `Cron Jobs`
2. از بخش `Common Settings` گزینه `Every 5 minutes` رو انتخاب کن
3. تو کادر `Command` این دستور رو بذار:

```
/usr/local/bin/php /home/USERNAME/public_html/cron.php >/dev/null 2>&1
```

> ⚠️ `USERNAME` رو با یوزرنیم سی‌پنل خودت جایگزین کن.

4. روی `Add New Cron Job` کلیک کن.

---

### روش دوم: Cron Job با wget ✅ (اگر PHP CLI در دسترس نیست)

بعضی هاست‌های اشتراکی دسترسی به `php` از خط فرمان رو مسدود می‌کنن. در این صورت:

۱. اول `CRON_KEY` رو از فایل `var/config.php` پیدا کن. این خط رو پیدا کن:

```php
define('CRON_KEY', 'xxxxxxxxxxxxxxxxxxxxxxx');
```

۲. تو `Cron Jobs` این دستور رو بذار:

```
wget -q -O /dev/null "http://yourdomain.com/cron.php?key=xxxxxxxxxxxxxxxxxxxxxxx" >/dev/null 2>&1
```

> ⚠️ حتماً `yourdomain.com` و `xxxxxxxx` رو با مقادیر خودت جایگزین کن.

۳. روی `Add New Cron Job` کلیک کن.

---

### چرا Cron هر ۵ دقیقه کافیه؟

TravianZ یه **حلقه داخلی** داره. وقتی cron.php اجرا می‌شه، ۳۰۰ ثانیه (۵ دقیقه) کار می‌کنه و هر ۶۰ ثانیه یک تیک پردازش می‌کنه — یعنی ۵ تیک در هر اجرا. پس حتی با Cron هر ۵ دقیقه، بازی هر ۶۰ ثانیه آپدیت می‌شه.

```
Cron اجرا می‌شه ← ۵ دقیقه کار می‌کنه ← Cron بعدی ۵ دقیقه دیگه
                 ← تیک ۱: ثانیه ۰
                 ← تیک ۲: ثانیه ۶۰
                 ← تیک ۳: ثانیه ۱۲۰
                 ← تیک ۴: ثانیه ۱۸۰
                 ← تیک ۵: ثانیه ۲۴۰
```

### اگر هاستت Cron هر ۱ دقیقه رو ساپورت می‌کنه

تو `var/config.php` این رو تغییر بده:

```php
define('CRON_LOOP_SECONDS', 0);  // بود 300 ← حالا 0
```

و Cron رو هر ۱ دقیقه تنظیم کن: `*/1 * * * *`

---

### 🔍 تست Cron Job

بعد از تنظیم Cron، ۵-۱۰ دقیقه صبر کن، بعد برو به:

```
http://yourdomain.com
```

وارد بازی شو و چک کن که:
- منابع توی village overview هر ساعت اضافه می‌شن
- اگه ساختمانی تو صف ساختی، تایمرش کم می‌شه

## عیب‌یابی

### ❌ صفحه سفید می‌بینم

۱. برو به `cPanel → Select PHP Version → Options`  
۲. `display_errors` رو `On` کن  
۳. صفحه رو refresh کن و خطا رو ببین  

راه‌حل‌های رایج:
- PHP ورژن 7.4 هست؟ → ببرش روی 8.0+
- `mysqli` فعال نیست؟ → از Extensions فعالش کن

---

### ❌ خطای "Can't connect to database"

۱. دوباره چک کن `var/config.php` — hostname، username، password، db name  
۲. تو `MySQL Databases` مطمئن شو کاربر به دیتابیس متصل شده  
۳. رمز دیتابیس رو ریست کن و تو config.php آپدیت کن

---

### ❌ Cron کار نمی‌کنه

۱. مطمئن شو مسیر PHP درسته. از `cPanel → Select PHP Version` مسیر PHP رو ببین و با چیزی که تو Cron نوشتی مقایسه کن  
۲. با wget امتحان کن بجای PHP CLI:  
```
wget -q -O /dev/null "http://yourdomain.com/cron.php?key=YOUR_KEY"
```  
۳. فایل `var/log/` رو چک کن (اگه خالیه یعنی cron اجرا نشده)  
۴. مطمئن شو `USERNAME` رو با یوزرنیم سی‌پنل خودت عوض کردی  
۵. ایمیل cron رو چک کن — سی‌پنل خروجی cron رو به ایمیلت می‌فرسته

---

### ❌ نقشه خالیه / ناتارها ظاهر نشدن

۱. دوباره نصب کن (پوشه install رو برگردون)  
۲. تو مرحله `Create World Data` صبر کن کامل تموم بشه — قطع نکن

---

### ❌ Cron ایمیل خطا می‌فرسته: "cron: unable to change to directory"

این مشکل وقتی پیش میاد که فایل‌ها رو تو مسیر اشتباه آپلود کردی. مطمئن شو `cron.php` تو `public_html/` هست (نه تو زیرپوشه).

---

### ❌ فونت فارسی / RTL کار نمی‌کنه

۱. مطمئن شو فایل‌های فونت وزیر تو `gpack/fonts/` آپلود شدن  
۲. فایل‌های مورد نیاز:
```
gpack/fonts/Vazir.woff2
gpack/fonts/Vazir-Bold.woff2
```
۳. از [github.com/rastikerdar/vazir-font](https://github.com/rastikerdar/vazir-font/releases) دانلود کن
